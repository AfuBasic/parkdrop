# ParkDrop Production Environment Configuration

This document specifies all configuration keys required to run ParkDrop safely in production. No secret credentials or sensitive API keys are committed to source control.

## Canonical Production Domains

- **Marketing / Web:** `https://parkdrop.com.ng`
- **Application (SPA):** `https://app.parkdrop.com.ng`
- **API (Laravel):** `https://api.parkdrop.com.ng`
- **WebSocket (Reverb):** `wss://ws.parkdrop.com.ng`

---

## Backend (`platform/backend/.env`)

### 1. Application & Core
| Key | Example Value | Description |
|---|---|---|
| `APP_NAME` | `ParkDrop` | Application display name. |
| `APP_ENV` | `production` | Strict production environment indicator. |
| `APP_KEY` | `base64:...` | Encryption key generated by `php artisan key:generate`. Required for session encryption. |
| `APP_DEBUG` | `false` | **MUST BE FALSE**. Disables public stack traces and error exposure. |
| `APP_URL` | `https://api.parkdrop.com.ng` | Canonical API URL used for email links and absolute URLs. |
| `APP_VERSION` | `1.0.0` | SemVer build identifier. |
| `FRONTEND_URL` | `https://app.parkdrop.com.ng` | Allowed origin for CORS and client redirection. |

### 2. Logging & Diagnostics
| Key | Example Value | Description |
|---|---|---|
| `LOG_CHANNEL` | `stack` | Stack logging channel combining daily logs and critical error alert channels. |
| `LOG_STACK` | `daily` | Rotated daily log driver. |
| `LOG_LEVEL` | `info` | Minimum log severity. Debug logs disabled in production. |
| `LOG_DAILY_DAYS` | `14` | Log retention window. |

### 3. Database (MySQL 8.4)
| Key | Example Value | Description |
|---|---|---|
| `DB_CONNECTION` | `mysql` | MySQL PDO driver. |
| `DB_HOST` | `127.0.0.1` | Database server host. |
| `DB_PORT` | `3306` | Database server port. |
| `DB_DATABASE` | `parkdrop` | Database name. |
| `DB_USERNAME` | `parkdrop_app` | Dedicated non-root MySQL user. |
| `DB_PASSWORD` | `[SECRET]` | Production database password. |

### 4. Sessions & Sanctum SPA Authentication
| Key | Example Value | Description |
|---|---|---|
| `SESSION_DRIVER` | `redis` | Fast, atomic session storage in Redis. |
| `SESSION_LIFETIME` | `120` | Session idle timeout in minutes. |
| `SESSION_DOMAIN` | `.parkdrop.com.ng` | Allows sharing authenticated session cookie across `app.` and `api.` subdomains. |
| `SESSION_SECURE_COOKIE` | `true` | Enforces HTTPS-only transmission of session cookies. |
| `SESSION_SAME_SITE` | `lax` | Cross-origin CSRF mitigation. |
| `SANCTUM_STATEFUL_DOMAINS`| `app.parkdrop.com.ng,parkdrop.com.ng` | Domains receiving stateful session cookies. |

### 5. Cache & Redis
| Key | Example Value | Description |
|---|---|---|
| `CACHE_STORE` | `redis` | Central application cache store. |
| `CACHE_PREFIX` | `pd_cache:` | Namespacing prefix preventing cache key collisions. |
| `REDIS_CLIENT` | `phpredis` | High-performance C extension for Redis. |
| `REDIS_HOST` | `127.0.0.1` | Redis host. |
| `REDIS_PORT` | `6379` | Redis port. |
| `REDIS_PASSWORD` | `[SECRET]` | Redis authentication password. |

### 6. Queues & Horizon
| Key | Example Value | Description |
|---|---|---|
| `QUEUE_CONNECTION` | `redis` | Queued jobs dispatched to Redis queues (`default`, `auth`). |
| `HORIZON_PREFIX` | `parkdrop_horizon:` | Redis prefix for Horizon metadata. |
| `HORIZON_PATH` | `horizon` | Web dashboard path (protected by gate). |

### 7. Reverb WebSockets
| Key | Example Value | Description |
|---|---|---|
| `BROADCAST_CONNECTION` | `reverb` | Real-time broadcasting driver. |
| `REVERB_APP_ID` | `[SECRET]` | Unique app ID. |
| `REVERB_APP_KEY` | `[SECRET]` | Public Reverb client key. |
| `REVERB_APP_SECRET` | `[SECRET]` | Reverb signing secret. |
| `REVERB_HOST` | `ws.parkdrop.com.ng` | WebSocket hostname. |
| `REVERB_PORT` | `443` | TLS port. |
| `REVERB_SCHEME` | `https` | Protocol scheme. |

### 8. Email (ZeptoMail / SMTP)
| Key | Example Value | Description |
|---|---|---|
| `MAIL_MAILER` | `smtp` | Mail transport. |
| `MAIL_HOST` | `smtp.zeptomail.com` | ZeptoMail SMTP gateway. |
| `MAIL_PORT` | `587` | TLS port. |
| `MAIL_USERNAME` | `emailapikey` | SMTP username. |
| `MAIL_PASSWORD` | `[SECRET]` | ZeptoMail send token. |
| `MAIL_FROM_ADDRESS` | `noreply@parkdrop.com.ng` | Verified sender address. |
| `MAIL_FROM_NAME` | `ParkDrop` | Sender display name. |

### 9. External Service Providers
| Key | Example Value | Description |
|---|---|---|
| `CLOUDINARY_CLOUD_NAME` | `parkdrop` | Cloudinary account name. |
| `CLOUDINARY_API_KEY` | `[SECRET]` | API Key for upload signing. |
| `CLOUDINARY_API_SECRET` | `[SECRET]` | Secret key used only on backend for cryptographic signatures. |
| `SMS_PROVIDER` | `termii` | Operational SMS provider (`termii`). |
| `TERMII_API_KEY` | `[SECRET]` | Termii production API Key. |
| `TERMII_SENDER_ID` | `OE Alert` | Registered Sender ID. |
| `PAYMENT_PROVIDER` | `flutterwave` | SMS-credit purchase payment provider. |
| `FLW_PUBLIC_KEY` | `[SECRET]` | Flutterwave public key. |
| `FLW_SECRET_KEY` | `[SECRET]` | Flutterwave secret key. |
| `FLW_SECRET_HASH` | `[SECRET]` | Webhook verification hash (`verif-hash` header). |
