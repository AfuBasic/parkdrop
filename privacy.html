Privacy Policy

ParkDrop is a tool for parcel pickup points to record packages and notify customers. This page explains what information is collected when you use the service.

Information recorded

When an attendant adds a package, ParkDrop records:

  • Customer name and phone number
  • Payment amount and status
  • Time of arrival and collection
  • An optional photo of the package

How it is used

The information is used strictly to manage parcel pickups:

  • To generate a unique package ID and pickup code
  • To automatically send an SMS to the customer when the package arrives
  • To help the attendant search for the package later
  • To keep a record of completed pickups

Contact

If you have any questions about this privacy policy, please contact us.
